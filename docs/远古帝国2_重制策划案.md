## 一、项目概述

### 1.1 设计愿景

将 2005 年 Macrospace 推出的经典 J2ME 战棋游戏《远古帝国2》以现代化品质重新呈现。保留"占领—经济—出兵—推进"的核心循环，在画面、操作、内容深度和社交体验上全面升级。

### 1.2 核心卖点

| 卖点 | 描述 |
|------|------|
| 🎯 易上手难精通 | 30 秒理解占领规则，数百小时研究兵种搭配 |
| 🧩 兵种相克 | 11 种单位，多维度克制链，不存在万能组合 |
| 🗺️ 地形策略 | 8+ 种地形影响移动与防御，站位即战术 |
| 📖 史诗战役 | 两大王国主线，42 关卡 + 全剧情对话 |
| ⚔️ 多人对战 | 异步回合 + 实时匹配，全球天梯排行 |
| 🛠️ UGC 生态 | 内置地图编辑器 + 地形生成器 |

### 1.3 地图与地形定位

地形不是背景，而是**第二套战斗系统**。本策划案提供：

1. **通用地形规格表**（第 5 章）——所有地图共用
2. **地图生成规则**（第 14 章）——程序化生成参数与种子算法
3. **战役关卡地图**（第 7 章）——42 关逐关的地形网格图
4. **剧情对话**（第 8 章）——6 章主线全程剧本 + 分支选择

## 二、核心玩法

### 2.1 游戏循环

```
占领据点 → 获取金币 → 招募部队 → 推进/歼灭 → 占领更多据点
```

### 2.2 回合流程

1. **经济结算**：村庄 +30 金/回合，城堡 +50 金/回合
2. **招募阶段**：在己方城堡/兵营中花费金币购买单位
3. **行动阶段**：依次操作每个单位——移动 → 攻击/占领/技能
4. **结束回合**：切换至对手/AI 回合

### 2.3 胜利条件

| 模式 | 胜利条件 | 失败条件 |
|------|----------|----------|
| 战役模式 | 完成关卡指定目标 | 指挥官阵亡且无法重新招募 |
| Skirmish | 占领所有敌方城堡 / 歼灭全部敌军 | 己方所有单位阵亡 |
| 多人对战 | 占领全部城堡 / 歼灭对方指挥官 | 己方指挥官阵亡 |

### 2.4 移动端操作

| 操作 | 功能 |
|------|------|
| 单指点击单位 | 选中，高亮可移动区域 |
| 再次点击目标格 | 移动 |
| 点击敌方单位 | 攻击（在范围内） |
| 双击己方单位 | 详细属性/技能 |
| 长按建筑 | 占领/招募菜单 |
| 双指缩放 | 地图缩放 |
| 滑动边缘 | 平移地图 |

```

弓箭手   ──▶ 飞龙                 （×1.5 伤害）
```

**克制倍率**：克制 ×1.5 ｜ 被克制 ×0.75 ｜ 无关系 ×1.0

### 5.2 地形策略要点

- **守点优先**：城堡/村庄 +15 防御 + 回血 + 产金，一举三得
- **森林伏击**：弓手藏森林射程受影响，但敌方近战进入会被反击
- **高地优势**：丘陵 + 弓手 = 射程 +1，形成压制
- **桥梁封锁**：狭窄桥梁适合石头人/士兵卡位，以少挡多
- **熔岩禁区**：熔岩格不可通行（飞龙除外），天然分割战场

## 六、伤害公式

### 6.1 基础公式

```
实际伤害 = 攻击方攻击力 × (当前HP / 100) × 克制倍率 × 暴击倍率
         − 目标方防御力 × (1 − 地形防御加成%)
```

### 6.2 参数范围

| 参数 | 说明 | 取值 |
|------|------|------|
| 攻击方攻击力 | 基础 + 升级 | 10 ~ 60 |
| 当前HP比例 | 残血衰减 | 0.01 ~ 1.0 |
| 克制倍率 | 兵种关系 | 0.75 / 1.0 / 1.5 |
| 暴击倍率 | 背击/高地 | 1.0 / 1.5 |
| 目标防御力 | 基础 + 升级 | 15 ~ 40 |
| 地形防御加成 | 格位加成 | 0% ~ 15% |

### 6.3 战斗示例

> 满血指挥官（攻35）攻击满血士兵（防25），士兵站森林（防+10）
> 35 × 1.0 × 1.0 − 25 × (1 − 0.10) = 35 − 22.5 = **12 伤害**

> 弓手（攻30）攻击飞龙（防30），弓对飞龙克制 ×1.5
> 30 × 1.0 × 1.5 − 30 = 45 − 30 = **15 伤害**

### 6.4 反击机制

- 近战攻击后，目标若存活且在范围内 → 自动反击
- 反击伤害 = 正常伤害 × **75%**
- 远程攻击后不触发反击（特殊技能除外）

## 十四、地图生成系统（程序化）

### 14.1 生成流程

```
种子 → 高度图(Perlin) → 生物群系判定 → 细节修饰 → 建筑放置 → 单位配置 → 验证
```

### 14.2 参数表

| 参数 | 范围 | 说明 |
|------|------|------|
| MapWidth | 10-26 | 地图宽度（格） |
| MapHeight | 8-18 | 地图高度（格） |
| WaterRatio | 0.0-0.4 | 水域占比 |
| ForestRatio | 0.1-0.3 | 森林占比 |
| MountainRatio | 0.05-0.2 | 山地占比 |
| SnowRatio | 0.0-0.3 | 雪地占比 |
| HillRatio | 0.1-0.25 | 丘陵占比 |
| LavaRatio | 0.0-0.15 | 熔岩占比 |
| VillageCount | 2-12 | 村庄数量 |
| CastleCount | 1-4 | 城堡数量（每势力 1） |
| ShrineCount | 0-3 | 神殿数量 |
| BarracksCount | 0-4 | 兵营数量 |

### 14.3 生物群系

| 群系 | 主地形 | 次地形 | 适用章节 |
|------|--------|--------|----------|
| 温带草原 | 平地/草地 | 森林 15% | 第一章 |
| 边境林地 | 森林 | 丘陵 20% | 第二章 |
| 亡灵荒原 | 雪地/山地 | 熔岩 10% | 第三章 |
| 联军雪原 | 雪地 | 山地 25% | 第四章 |
| 龙焰峡谷 | 熔岩 | 山地 30% | 第五章 |
| 终局之地 | 熔岩/雪地 | 山地 20% | 第六章 |

### 14.4 验证规则

1. 所有城堡必须可达（BFS 连通性检查）
2. 玩家与敌方城堡距离 ≥ 8 格
3. 村庄分布均匀（每 4×4 区域至少一个）
4. 熔岩不可包围任一城堡
5. 水域不可完全切断任一阵营
6. 桥梁数量 1-3，且连接双方领地

### 14.5 种子示例

| 种子 | 产物 | 备注 |
|------|------|------|
| `AE2_CLASSIC` | 14×10 温带草原 | 致敬原版 |
| `AE2_SNOW` | 16×11 雪原 | 第二章 2-5 |
| `AE2_LAVA` | 20×14 熔岩峡谷 | 第五章 5-4 |
